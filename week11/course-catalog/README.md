# Course Catalog — Week 11 React Practice

This follows the **Course Catalog Practice Challenge** in the teacher's Week 11 Friday **Video Lecture** (slide 13).

It includes:
- `CourseCard` props: `title`, `instructor`, `credits`, `required` (boolean).
- Red **필수** badge when required is true, grey **선택** badge otherwise.
- `CourseCatalog` that uses `.map()` with stable `course.id` keys.
- The three example courses from the teacher's video lecture.

## Run the Vite React source

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

https://eric2626.github.io/Web-programming-live-site/week11/course-catalog/live/
