# Week 11 – ProductCard Code Challenge

Based on the Week 11 Friday **React Components & Props** lecture, PDF page 19.

## Requirements
Create a React `ProductCard` component that receives:
- `name` — product name (string)
- `price` — price in Korean won (number)
- `rating` — rating from 0 to 5 (number)
- `inStock` — whether the item is available (boolean)

**Bonuses implemented:** display rating as `4.5 / 5 stars`; show `Out of Stock` when `inStock` is false.

## Files
- `ProductCard.jsx`: reusable JSX component
- `index.html`: self-contained React example (CDN React, plus HTML fallback)
