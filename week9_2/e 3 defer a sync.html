Code pattern for real websites

<head>
  <script src="app.js" defer></script>
  <script src="analytics.js" async></script>
</head>

defer: downloads in parallel, runs after HTML parsing, and preserves order among deferred scripts.

async: downloads in parallel, runs as soon as available, and does not guarantee execution order.

Important: This practice file embeds both tiny scripts as data URLs so it works as one HTML file. In a real project, save them as separate JavaScript files.

Test it

  1. Reload the page and check that the status turns green.
  2. Open Chrome DevTools → Console.
  3. Find the two messages about defer and async.
  4. Check that the app found its DOM element.
