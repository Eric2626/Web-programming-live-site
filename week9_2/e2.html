picture + source + srcset

Responsive landscape photo

The browser tries WebP first. If it cannot use WebP, it falls back to JPEG.

What was added: <picture>, <source type="image/webp">, srcset, sizes, alt, width and height.

Compare the formats

JPEG

A good photo format, but its file size may be larger.

WebP

Often smaller at similar visual quality. Supported by modern browsers.

Bonus: fetchpriority="high" helps prioritize the hero image.

Test in Chrome

  1. Press F12 → Network.
  2. Reload this page and select the image request.
  3. Check the image Type and Size.
  4. Resize the browser. Check how the image request changes with the viewport.

Note: This example uses an online image service. Internet access is needed to load the photo.
