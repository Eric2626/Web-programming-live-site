Web Development Questions

What is HTML used for?

HTML is used to create and organize the structure of web pages. It defines elements such as headings, paragraphs, images, and links.

When should we use section and article?

A section is used to group related content on a page. An article is used for independent content such as a blog post, news story, or forum post.

Why should images have alt text?

Alt text describes an image when it cannot be displayed. It also helps screen reader users understand the image content.

Why do we write DOCTYPE in HTML?

The DOCTYPE tells the browser that the page uses HTML5. It helps the browser display the webpage correctly.
